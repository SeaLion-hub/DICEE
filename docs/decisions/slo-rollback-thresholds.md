# SLO·롤백 임계치 (단일 소스)

Runbook은 이 문서를 **참조만** 하고, 수치를 중복 기재하지 않아 드리프트를 방지한다.

## SLO (v1)

- **API 가용성**: 99.5% (30일)
- **API 지연**: p95 < 1.5s
- **크롤 성공률**: 99.0% (24h rolling)
- **신선도**: 95% 작업이 due+15분 내 완료

## 알럿 (multi-window burn-rate)

- **Critical(Page)**: burn-rate **>14.4**를 **5m**와 **1h**에서 동시 만족
- **Warning(Ticket)**: burn-rate **>6**를 **30m**와 **6h**에서 동시 만족
- **최소 트래픽 게이트**: API **300 req/5m** 이상 또는 크롤 **200 jobs/15m** 이상 (미충족 시 알럿 미발화)

## 롤백 트리거 (아무거나 1개 충족 시)

- Critical burn-rate 상태 **10분** 지속
- **queue_depth** > 7일 기준선의 **3배**가 **30분** 지속
- **DLQ 유입률** > **1%**가 **30분** 지속
- 신선도 SLO **90% 미만**이 **30분** 지속
