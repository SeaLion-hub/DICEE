# SecretStr 사용 규칙 (ADR)

**상태**: 채택  
**배경**: Pydantic `SecretStr`로 시크릿을 감싼 뒤 `get_secret_value()`를 여러 레이어에서 호출하면, 예외 메시지·스택 트레이스에 평문이 유출될 위험이 있다.

---

## 결정

- **호출 범위**: `get_secret_value()`는 **필요한 최소 레이어**에서만 호출한다. config 검증(예: production 필수 검사)과 실제 사용처(인증·헤더 비교·Sentry DSN 등)에서만 풀어 쓴다.
- **예외·로그**: 시크릿 값을 **예외 메시지(`str(e)`)** 또는 **로그 포맷 인자**에 넣지 않는다. 로그에는 "값이 설정됨/없음" 정도만 남긴다.
- **점진적 개선**: 가능하면 시크릿을 풀어준 값을 인자로 넘기고, 서비스/라우터는 설정 객체가 아닌 이미 풀어준 값을 받도록 리팩터하면 노출 구간을 줄일 수 있다.
